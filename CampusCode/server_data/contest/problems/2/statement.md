# Problem 2: Multiplication

## Description
Given two integers, output their product.

## Input
Two space-separated integers a and b.

## Output
Print the product of a and b.

## Constraints
- -10^9 ≤ a, b ≤ 10^9

## Examples
### Example 1
Input:
```
5 3
```
Output:
```
15
```

### Example 2
Input:
```
7 8
```
Output:
```
56
```
