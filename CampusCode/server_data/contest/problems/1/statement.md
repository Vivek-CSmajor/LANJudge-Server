# Problem 1: Simple Addition

## Description
Given two integers, output their sum.

## Input
Two space-separated integers a and b.

## Output
Print the sum of a and b.

## Constraints
- -10^9 ≤ a, b ≤ 10^9

## Examples
### Example 1
Input:
```
2 3
```
Output:
```
5
```

### Example 2
Input:
```
10 20
```
Output:
```
30
```
