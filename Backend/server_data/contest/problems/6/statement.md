# Problem 6: Grid Paths

## Description
Given n and m, count ways to reach (n,m) from (1,1) moving only right or down. Output modulo 1e9+7.

## Input
One line with n and m.

## Output
Print one integer: number of paths modulo 1000000007.

## Constraints
1 <= n, m <= 2000

## Examples
### Example 1
Input:
```
3 3
```
Output:
```
6
```
