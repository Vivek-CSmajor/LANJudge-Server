# Problem 5: Pair Difference

## Description
Given a sorted array and integer K, count pairs (i,j) where j > i and a[j] - a[i] = K.

## Input
First line: N K. Second line: sorted array of N integers.

## Output
Print one integer: count of valid pairs.

## Constraints
1 <= N <= 200000, 0 <= K <= 10^9

## Examples
### Example 1
Input:
```
5 2
1 3 5 7 9
```
Output:
```
4
```
