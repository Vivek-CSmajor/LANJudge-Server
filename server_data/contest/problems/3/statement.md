# Problem 3: Array Sum

## Description
Given an array of N integers, print the sum of all values.

## Input
First line: N. Second line: N space-separated integers.

## Output
Print one integer: total sum.

## Constraints
1 <= N <= 200000, |a_i| <= 10^9

## Examples
### Example 1
Input:
```
5
1 2 3 4 5
```
Output:
```
15
```
