# Problem 4: Maximum Subarray

## Description
Given N integers, find the maximum possible contiguous subarray sum.

## Input
First line N, second line contains N integers.

## Output
Print one integer: maximum subarray sum.

## Constraints
1 <= N <= 200000, |a_i| <= 10^9

## Examples
### Example 1
Input:
```
8
-2 -3 4 -1 -2 1 5 -3
```
Output:
```
7
```
