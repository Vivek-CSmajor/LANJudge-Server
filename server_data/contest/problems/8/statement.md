# Problem 8: Prime Queries

## Description
For each query x, answer if x is prime.

## Input
First line Q, followed by Q lines each containing x.

## Output
For each query print YES or NO.

## Constraints
1 <= Q <= 100000, 1 <= x <= 10^7

## Examples
### Example 1
Input:
```
3
2
15
17
```
Output:
```
YES
NO
YES
```
